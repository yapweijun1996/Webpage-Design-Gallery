Foundations

Color defines meaning. Shape groups content. Elevation establishes hierarchy.

Color and contrast

Each swatch shows its foreground on its assigned surface. Pair the listed tokens and use text to communicate status.

  • CanvasPage background--dc-ink / --dc-bg
  • SurfaceSupporting copy--dc-muted / --dc-surface
  • Tinted surfaceGrouped content--dc-ink / --dc-surface-2
  • BrandPrimary action--dc-on-brand / --dc-brand
  • SuccessChanges saved--dc-success / --dc-success-bg
  • WarningReview required--dc-warning / --dc-warning-bg
  • ErrorChanges could not be saved--dc-error / --dc-error-bg
Action states and contrast

Brand actions use --dc-brand at rest and --dc-brand-dark on hover and press, with --dc-on-brand in every state. Use --dc-focus for the offset keyboard ring. Use muted text and inactive semantics for disabled actions. Reserve the error pair for failure feedback.

Contrast target for normal text is 4.5:1 in both schemes. Keep --dc-line for decorative separation and use a stronger edge when a boundary identifies a control.

Shape

The corner radius identifies the element type. Use larger radii on larger containers and reserve pills for compact labels.

  •  Inset--dc-radius-sm
  •  Control--dc-radius
  •  Panel--dc-radius-lg
  •  Label--dc-radius-pill

Elevation

The surface edge and shadow indicate depth. Use the lowest level that expresses the layer.

  • FlatIn-flow content--dc-line
  • RaisedCard above canvas--dc-shadow-1
  • FloatingPopover above content--dc-shadow-2
