# GJH and New Moon — Source-Verified Asset Library

Captured from GJH corporate and GJH eShop official origins on 11 November 2026. This is a project research library, not an official brand portal or a claim of current brand approval.

## What source-verified means

Each original file was downloaded successfully from an allowlisted official host. Its source page was fetched and checked for a reference to that asset's URL path. `manifest.json` records HTTP status, capture time, original URL, final URL, referring page, dimensions, byte size and SHA-256. Product packshots are tied to the exact eShop product page and title. Source-page receipts include content hashes; raw HTML is not retained in this repository.

This proves source provenance at capture. It does not establish the current packaging edition, a legal trademark registration, licensing terms, certification validity, or endorsement of this concept. Permission for this project's use was confirmed by the user in the conversation; no independent licence document was supplied.

## Verification

Run `python scripts/verify_gjh_asset_library.py` from the repository root. The offline check verifies local file integrity, source-host boundaries and recorded page-context evidence. Refresh sources and edition status before a new campaign. Originals must remain unchanged; save approved derivatives under distinct names with a link to the original asset ID and a transformation record.

The current Pages build does not include this library. No V3 mockup or public-site replacement is part of this research update.
