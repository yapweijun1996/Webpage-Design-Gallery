# GJH landing-page image library

98 individual WebP assets generated with OpenAI ImageGen for the [GJH landing-page image brief](../../../../docs/gjh-landing-image-brief.md). These independent editorial concepts include fictional scenes and generic props. Use approved originals when identifying a real product or displaying a brand mark. Product stages are intentionally empty.

Use the manifest to find each file, brief, dimensions, alpha flag, byte size and SHA-256. Assets 075–082 and 091–098 have transparent backgrounds. The links below open the individual images.
