# MILI 510 g sauce bottle geometry

This Blender study uses the nominal 55 × 55 × 245 mm dimensions published by Goh Joo Hin for both sauces. The front photographs establish the shoulder and red-orange closure. The cross-section is an inferred cylinder. The study is intentionally unprinted. [Regular oyster sauce](https://www.gjheshop.com/product/mili-oyster-sauce-510g/) · [Vegetarian oyster sauce](https://www.gjheshop.com/product/mili-vegetarian-oyster-sauce-510g/)

Open the Blender file to inspect the Detailed study. Run `blender --background --python generate.py` from this directory to regenerate Low, Balanced and Detailed studies under `exports/`. The showroom integrates a lighter pair of bottle forms in its existing room-detail GLB. [Room-detail source](../../scripts/gjh_interiors/rooms.py)
