# GJH eight-asset interior pilot

Open `demos/corporate/gjh/v11/index.html?interior=pilot` for all eight assets. The default route retains the later released M056 shelf; seven other pilot assets are shared. Pilot shelf positions/supports/bounds are selected together so the existing Shelf focus and pickup/return state machine remains authoritative.

Eight editable Blender sources and static runtime GLBs implement the pilot selected in [task.md](../../task.md). [manifest.json](manifest.json) records each candidate's original priority/dimensions, reviewed target, reuse decision, provenance, export hash, collision authority, capabilities and G01–G12 applicability. The runtime registry/receipt are generated by `build.py`; change the source and rebuild them together.

Three assets reuse original owner-project geometry (bench, planter, shelf); the kiosk adapts an original model to three numbered destinations. Four new models supply the storefront frame, wall light, coffee table and atrium plinth. Existing official brand artwork remains separate from the blank storefront frame. This delivery grants no additional trademark or third-party asset rights.

## Reproduce

Use Blender 5.1.2 or compatible, Python 3.10+, and the locally installed Khronos `gltf-validator` Node module. Set paths for your installation; no network download or new npm dependency is required.

```sh
BLENDER='/Applications/Blender.app/Contents/MacOS/Blender'
UPSTREAM='/path/to/Blender-3D-Gallery'
"$BLENDER" --background --factory-startup --python-exit-code 1 --python models/gjh-interior-pilot/build.py -- --upstream "$UPSTREAM"
"$BLENDER" --background --factory-startup --python-exit-code 1 --python models/gjh-interior-pilot/inspect_sources.py
"$BLENDER" --background --factory-startup --python-exit-code 1 --python models/gjh-interior-pilot/verify_render.py
node models/gjh-interior-pilot/validate.mjs "$UPSTREAM/node_modules/gltf-validator"
python3 -m unittest discover -s tests -p test_gjh_interior_pilot.py -v
python3 tests/browser_gjh_interior_pilot.py
python3 tests/browser_gjh_interior_pilot_performance.py
python3 scripts/build_gallery.py
python3 scripts/build_gallery.py --check
```

The upstream source paths and hashes are in the runtime receipt. They are read only. Four original files were authored with a newer Blender and emitted a version warning on 5.1.2; evaluated static geometry was successfully re-exported, independently reimported and verified. Editable delivery copies live here, preserving the originals. Blender may create `.blend1` save backups on rerun; those are not delivery artifacts.

## Runtime contracts

- One metre per Blender unit; Blender W/D/H becomes glTF X/Z/Y. Origins are ground-centred. Bounds use evaluated vertices, including text/curves, rather than loose control-point bounds.
- Visual GLBs contain static glTF PBR material primitives, no textures, external buffers, animation, skinning or decoders. The loader retains SHA-256, identity, bounds, primitive-count and eight-second deadline checks.
- One geometry/material set is instanced across placements. LOD0/1/2 authoring collections are organization only: the explicit single-level instance/simple-asset exemption applies. No automatic LOD switching is claimed.
- Rapier collision remains app-owned in `world.js` / `products.js`. Authoring collision/socket collections are excluded from the visual GLB. The manifest records exact pilot blockers or the owning implementation.
- Bench `SIT`, kiosk `USE` and shelf/product `INSPECT` use existing application anchors/actions. Other pilot props are passive. No invented seating on tables/planters or extra live brand is added.
- A failed individual GLB keeps its procedural fallback. A parse finishing after its deadline is disposed. Directory/product browsing remains usable without WebGL.

[Review and limitations](../../docs/gjh-v11-interior-pilot-review.md) links browser evidence and before/after captures. Authoring sources and reports are excluded from the generated Pages artifact. The remaining 192 candidate assets are pending.
