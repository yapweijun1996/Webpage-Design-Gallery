# GJH landing-page roadmap and review guide

Eight independent, English-language landing concepts let a reviewer test different reasons to visit Goh Joo Hin. The existing five introduce the company. The three new concepts serve a meal planner, an electronics visitor and a retail buyer. The GJH collection has sixteen designs.

## Parallel delivery and release checks

1. **Design and content.** One owner per new page works from a separate visitor brief. The editorial lane owns occasions, the electronics lane owns channel navigation, and the buyer lane owns form state. A shared asset library records source IDs and hashes.
2. **Integration.** Keep runtime artwork with each demo. Only selected sizes travel to the published site. The repository holds the complete [98-image library](../assets/companies/gjh/landing-concepts/README.md). Keep official corporate photography and marks traceable to their respective source records.
3. **Browser acceptance.** Exercise all eight direct URLs at 320, 390, 768 and 1440 CSS pixels. Inspect the lead image and headline, follow a primary action and verify its destination. Test keyboard focus, native anchors, reduced-motion mode, no-JavaScript reading paths at 320 and 390, and axe at 390 and 1440. Check the actual Pages artifact, including its images, CSS and JavaScript.
4. **Gallery and release.** Verify live and screenshot comparison, desktop/tablet/phone previews, source-generated catalog consistency and service-worker integrity. Run repository checks, push to main, confirm the deployed build and open the public routes.
5. **Owner review.** First compare V12 with V17 for food discovery. Compare V15 with V18 for electronics. Compare V13 with V19 for business enquiries. Have a visitor unfamiliar with each pair complete one task without coaching. Record the action taken and the point of hesitation alongside visual preference. These observations can inform the next prototype.
