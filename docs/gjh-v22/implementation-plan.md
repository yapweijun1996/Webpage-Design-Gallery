# GJH v22 "Brand Chapters" - implementation plan (manager + advisor review, 2026-11-18)

Approved direction: `mockups/desktop-1440.png` and `mockups/mobile-390.png` (full-bleed cinematic chapters from the repo image library) + `mockups/enquiry-sheet-desktop.png|mobile.png`. `design-brief.md` is the concept authority, `planning-brief.md` the business authority, `design-notes.md` the type/palette/image plan. The v20/v21 merged pages are behavioural references (enquiry, registration).

## Corrections to the mockup (mandatory)
1. Unique imagery: the hero and the New Moon chapter must NOT use the same photo (desktop repeated the abalone platter; mobile repeated the spoon). Hero = a different library image (e.g. a GJH editorial spread 069/072/074 or another strong frame that carries text), New Moon chapter = its own (001/002/003). Every chapter and the About/Mall bands use a distinct image; write the id table in design-notes.
2. Scrims: no edge-to-edge darkening. Use a localized gradient only behind the text block (and a light top gradient behind the nav); keep each photo's colour (GOGO must stay sunlit). Measure contrast >= 4.5:1 for every text-over-image block against the actual local scrim and record the numbers.
3. Rhythm: do not repeat five identical left-aligned slabs. Mirror the text alignment on at least one chapter, keep at least one chapter light-themed (text on a light panel) and vary the action placement; New Moon keeps its packshot card.
4. More brands rail: use each brand's own library hero/story frame (LG 053/054, Casio 057/058, GP Batteries 061/062, Gigaset 065/066), text wordmarks unless a logo has verified provenance in the repo, and link ONLY to the official brands directory (no unverified brand URLs).
5. Enquiry sheet: reuse the tested behaviour from v20/v21 (brand prefilled from any Enquire action, free-text product field, message preview, Copy details with read-only textarea fallback that works inside the gallery iframe preview, Open official contact, NO submit button or success message, plain note to paste into the official Message field). Static Sales Enquiry section uses the same component. Works without JS through direct official links.
