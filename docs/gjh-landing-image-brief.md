## Prompt recipes

Start a batch with 001, 009, 021, 045, 049 and 057 to review six different subjects in the same desktop layout. Pair 001 with 002 at 390px to test whether the mobile framing works. Try 004 with an existing approved New Moon packshot before commissioning more stages.

**001 · Desktop hero**

> Create one photorealistic editorial image for an independent Singapore food landing page. A hand sets an oval porcelain platter of sliced braised abalone onto an ivory linen table. Use the right half for the serving gesture and platter. Leave the left 45 percent as softly lit linen for a live HTML headline. Warm late-afternoon light from the upper left, natural food color, gentle shadows, eye-level three-quarter view. Compose for a 16:9 landscape crop. No text, logos, packaging or watermark.

**004 · Empty product stage**

> Create one e-commerce background plate. Centre a low celadon saucer on a deep plum matte table, camera level with the front of a small tin. Leave space above the saucer and a clean contact surface for a real packshot to be added later. Soft key light from upper left, restrained fill, no hard cast shadows across the placement area. Compose for 4:5 portrait. Render only the empty set with no product, packaging, labels or text.

**075 · Original illustrated category icon**

> Create one square transparent-background editorial icon of a rice bowl with a single rising curl of steam. Two layers of cut paper, warm ivory bowl and terracotta detail, rounded silhouette, a little side-light depth. Centre the entire object inside generous padding. No letters, logos, border or surrounding scene. The silhouette should still read at 64px.

Use IDs as filenames, for example `gjh-001-new-moon-reunion-desktop.webp`. Keep editable masters. Export photos as WebP or AVIF and use alpha-enabled files for isolated objects. Keep headlines, action labels and disclosures as HTML. Use the gallery's existing SVGs for navigation controls. Check each hero and the most detailed card in the existing desktop and mobile layouts before expanding a batch.
