# Mini Street: New Moon product model audit

Checked 2026-11-24 for the unofficial Mini Street concept. This is an asset
inventory and does not assert current price, inventory, or packaging approval.

## Existing interactive models

The Mini Street catalog uses four GLB cans: Australia 425 g, New Zealand 425 g,
South Africa 425 g, and Mexico 454 g. Their exact asset hashes and the existing
public-demo permission are recorded in
[v11/assets/newmoon-demo-source.json](../demos/corporate/gjh/v11/assets/newmoon-demo-source.json).
The underlying [Blender can project](https://github.com/yapweijun1996/Blender-3D-Gallery/tree/b89cffaf85aab46deb91b01ee3dbfe2e8b1b58da/models/gjh-abalone-cans)
contains higher-detail versions of the same four items. AI-redrawn label
alternatives are not independently verified product packaging.

No additional distinct, identified New Moon product GLB was found in the
reviewed Blender Gallery inventory, Website Gallery assets, or targeted public
model searches. This is the result of a bounded search, not a claim that no
other models exist.

The existing `v11/assets/gallery-assets/abalone-gift-box-display.glb` is a
generic, unbranded, static display fixture. It is not evidence of an actual
New Moon gift-set SKU and should not be catalogued or presented as one.

Before presenting another exact SKU, establish the model and label source,
permitted use in the published concept, current pack variant, physical
dimensions, and enough packaging views to avoid inventing rear labels. Store
these facts with the asset. Test the resulting model against the shelf, hand
contact, browser memory budget, and basket migration. The current virtual
basket records selections only.
