# New Moon flat-label concept candidates

These are unofficial, AI-generated estimated wrap concepts for visual review, not certified or brand-approved packaging replicas. The original source images are preserved. Panel order, dimensions, wrap spacing, current packaging edition and brand approval are unverified. Unknown side and rear sectors use decorative continuation; ingredients, nutrition values, barcodes, dates, addresses, certifications, awards and prices are not supplied. Do not use as production artwork.

Method: built-in `image_gen.imagegen`, using each front packshot as its image reference. The native tool did not disclose its model name. The back and nutrition images were inspected for context, but were not passed to the generator. Exact prompts, all native output paths and selected attempts are in [prompts.json](prompts.json).

The first NZ image included a certification-style mark; the first AU and SA images included badge-like embellishments or extra copy. Each was regenerated once with a targeted request to remove badges. All seven native generation calls succeeded. One retry orchestration failed before a native call because a stored value was unavailable (`TypeError: Cannot read properties of undefined (reading 'find')`); it was resubmitted.

candidates, with a set-level subjective score of 88/100. See [acceptance.json](acceptance.json)
for verified scope. AI-reconstructed lettering/moon faces are not original artwork;
seamless tiling, true wrap dimensions, panel order and GLB texture suitability are
not established. The candidate directory is excluded from the Pages artifact.
The current application and its published textures are unchanged.
