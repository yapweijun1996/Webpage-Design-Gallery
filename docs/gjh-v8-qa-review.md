# GJH V8 QA Review

Reviewed: 11 November 2026. Scope: `demos/corporate/gjh/v8/`, its gallery metadata and the local browser evidence generated by `tests/browser_gjh_v8.py`.

This is an independent design concept. The review measures the local static artifact, not a production deployment, field performance, company approval or conversion outcome.

## Evidence

- Five reduced-motion Chromium cases passed at 1920×1080, 1440×900, 768×1024, 390×844 and 320×568.
- Normal-motion checks passed for hero scroll variables, desktop brand depth and pointer tilt, automatic timeline activation, skip-link focus, mobile navigation target focus and the 900px breakpoint focus recovery.
- The page exposed 13 images at every tested viewport. All decoded successfully; no tested page emitted a console error or HTTP response at status 400 or above.
- Gallery entry, V8 detail, V8/V7 comparison, V1/V5/V6/V7 route smoke checks and the no-JavaScript V8 fallback passed.
- axe-core 4.14.0, SHA-256 `20c09fe157a8a34a30e241aaa1fcdade657734f08ab379ecfbeb7d45cc46e878`, reported zero WCAG A/AA violations at 1440×900 and 390×844.
- Clean full-page captures and a generated thumbnail are recorded in `docs/evidence/gjh-v8-browser.json`.

## Persona review

### Accessibility Specialist — PASS; residual risk LOW

Evidence: The skip link receives focus with Tab and transfers focus to `main` on Enter. Mobile navigation closes with Escape and returns focus to the menu button. Navigation links move focus to their section target on mobile. Reduced-motion contexts passed without layout overflow, and the axe 4.14.0 A/AA run found no violations at desktop or mobile representative widths.

Recommendation: Keep the existing semantic headings, visible focus outlines, target focus behavior and reduced-motion rules. Before a public release, complete a manual screen-reader and physical keyboard pass, including the externally opening brand and contact links.

Verification: Automated keyboard, reduced-motion, no-JavaScript and axe checks PASS. Manual assistive-technology and complete WCAG conformance remain UNVERIFIED.

### Mobile UX Specialist — PASS; residual risk MEDIUM

Evidence: The 768px, 390px and 320px cases passed without horizontal overflow. The 390px normal-motion case passed mobile menu target focus and focus recovery when crossing the 900px breakpoint. Brand cards, business cards, market controls and timeline controls remain reachable in the stacked mobile layout.

Recommendation: Validate the 320px composition on a physical device and test touch scrolling while the menu is open. Confirm that the small source imagery and explanatory notes remain legible on actual iOS Safari and Android Chrome.

Verification: Required emulated viewport and interaction checks PASS. Physical-device, Safari and Android validation remain UNVERIFIED.

### QA Engineer — PASS; residual risk LOW

Evidence: The harness builds a temporary GitHub Pages-style artifact, checks the five required viewports, decodes all 13 images, rejects failed HTTP responses and console errors, exercises stateful era/timeline/market controls, verifies V8 gallery integration and compares V8 with V7. Existing V1/V5/V6/V7 routes return successful responses with visible headings. Gallery unit tests pass 8/8 and the deterministic build check reports 1 company and 5 designs.

Recommendation: Keep the V8 suite as the focused regression gate when V8 assets or interaction logic change. Run the existing full legacy browser suite separately when its screenshot outputs are intentionally refreshed.

Verification: Focused browser, unit and generator checks PASS. Cross-browser and production-host verification remain outside this run.

### Performance Engineer — PASS for local static checks; residual risk MEDIUM

Evidence: The page uses local assets, a self-hosted font, lazy-loaded below-fold images, CSS/native motion and no WebGL dependency. The browser run produced no failed resource responses, no console errors and no overflow at the tested widths. The harness records decoded image counts and clean screenshot state.

Recommendation: Keep the current no-runtime-dependency architecture. Use Lighthouse and field telemetry on the deployed artifact before making a performance claim; measure LCP, CLS, INP and transfer cost with the final hosting headers and image compression.

Verification: Local resource and interaction checks PASS. Lighthouse and field Core Web Vitals are not established by this report.

### SEO Specialist — PASS for page-level foundations; residual risk LOW

Evidence: The page has a descriptive title, meta description, theme color, Open Graph title/description/type, one primary `h1`, section headings and crawlable anchor navigation. The no-JavaScript case preserves the document structure and navigation links.

Recommendation: Add a deployment-specific canonical URL and validate the final Pages URL, robots policy, sitemap behavior and social-card rendering before publication. Keep concept disclaimers and factual qualifiers visible in the page copy.

Verification: Local title, description, heading and no-JavaScript checks PASS. Search indexing, canonical resolution and social crawler behavior remain UNVERIFIED.
