# GJH v11 UX — exploration and shop HUD

## Round 1 implemented scope

- **P0-1 Tutorial:** `assets/ux-tutorial.js` replaces the blocking welcome with a nonmodal Getting Started card. Desktop width is 300px; mobile uses a compact edge sheet above the joystick and bottom bar, below the viewport centre. Skip, Back and Next/Done accompany a numeric 1/3 counter and three progress segments. Confirmed translation, camera yaw and successful registry dispatch advance only the current step. Opening a panel suspends the card, not the other way around. Automatic progress never moves focus. Skip/Done returns focus to the scene.
- **Viewer memory:** `localStorage` key `gjh-v11-tutorial-v1` stores `dismissed` or `completed`. Access and writes are guarded; memory-only dismissal works when storage is blocked. Guide in the right rail and Show quick guide in Help explicitly replay it. The old session welcome flag and shared onboarding modal are no longer used by v11. Previously saved shared language/theme preferences remain readable for amenity dialogs.
- **P0-2 Controls:** the persistent desktop bar shows WASD Move, Mouse Look (drag), Shift Run and F - Interact only while an interaction is available. There is no Escape-to-open menu, so no fictional ESC Menu hint is added. Mobile hints describe the existing floating joystick, Run toggle, two-finger camera gesture and contextual tap action. The tutorial does not overlap that bar or the walking controls at the requested portrait size.
- **P1-1 Navigation:** one top bar holds GJH / VIRTUAL MALL, the Courtyard/location chip, Map, inventory Bag and Store Directory. Guide, Help, Shopping Cart and Theme share a right-side rail; there are no loose left action buttons. Bag holds collected demo selections, not purchases. Shopping Cart is the existing physical push-cart demo; no checkout, payment, order or reservation is invented. Physical shelf pickup remains its separate existing interaction. Labels, tooltips and accessible names distinguish the two.
- **P1-2 Orientation:** `assets/ux-spatial-hud.js` supplies Floor 01 - Atrium / Floor 02 - Upper Level, the desktop Mini Map and a near-target distance hint. The Mini Map clones the already-configured classic/expanded SVG plan once, removes IDs and data attributes, and updates only the position/heading and context. Upstairs/in transit it hides the ground-floor player marker and identifies the plan honestly. Mobile hides the Mini Map; the full map remains available from the header at every width and starts closed. The existing nearby action card supplies mobile target identity.

## Integration and constraints

`script.js` uses the existing registry selection and action-button availability, never a second proximity scan. Registry success subscribers cover doors, benches, products, amenities and travel, including handlers registered after startup. Failed dispatch does not advance the tutorial. The F hint disappears outside range, while travelling, during covered modes and interruptions.

All additions are DOM/SVG, with no scene objects or rendering passes. NPC admission, Bloom, shop interiors and S01 assets are unchanged. The viewport retains `maximum-scale=1, user-scalable=no`. There are no new dependencies or GitHub Actions.

HUD icons use the existing `assets/icons.js` registry, generated by `scripts/sync_gjh_icons.py` from SVG-Icon-Studio. All required icons already exist; no drafts or ad-hoc icon SVGs were needed. Mini Map paths are reused spatial geometry, not icons.

## Gaps and verification scope

There is no dedicated camera button: touch camera control is the existing two-finger gesture, documented by hints. Quests and a menu-opening Escape action do not exist and were not added. Mini Map is intentionally hidden on mobile. Viewer memory cannot survive reload if local storage is denied. Physical-device safe areas and screen-reader acceptance remain unperformed.

The allowed browser acceptance entry is `tests/browser_gjh_v11.py`; it now exercises real movement/look/F tutorial progression, Back/Next, dismissal/replay/reload persistence, HUD geometry and screenshots at 1440×900 and 390×844. Existing feature browser callers were migrated to the new startup contract, but those separate suites were not executed, as requested. Node tests cover sequential progress, denied storage, registry success events, map projection/floor context and proximity visibility.
