# Desktop and mobile landing-page audit

The audit compares each published edition with its primary reference at the start of the review ([baseline a9918fe](https://github.com/yapweijun1996/Webpage-Design-Gallery/tree/a9918feb53d4ad9a6f292083ba25f47127e8d9ed)). Each sheet shows the original mockup, the actual desktop first screen at 1440 × 900 and the phone first screen at 390 × 844, before and after the changes. The images preserve the complete captured viewport. Open the sheet at full size to inspect details.

The primary references are desktop compositions. On phones we checked the subject, reading order, primary action and legibility through reflow. Company notes record intentional changes of scale or order and any limitations.

| Company | Pages | One change visible in the comparison sheets |
| --- | ---: | --- |
| Goh Joo Hin | 16 | The arrivals board now shows four product origins and pack weights at entry. Visitors can go directly to a product or enter the walkable mall. |
| Thow Kwang Pottery Jungle | 15 | The dragon kiln fills the opening spread. Each of its three labelled zones can be selected independently on the phone. |
| Yeo Hiap Seng | 15 | The cooler opens with an illuminated cabinet and working container filters. The soy edition puts the two drinks' available package sizes side by side. |

The 14 alternate directions remain in the atlas. The comparisons below use the primary reference assigned to each live edition. The browser evidence covers the initial screen; product details and visitor information follow the cited sources on each demo.

## Verification

The Chrome captures cover all 46 primary references at both viewport sizes. The baseline mall's phone image is a frame from a real 390 × 844 browser recording of the settled 3D scene. The revised mall opens on its arrivals board. Each of the other comparisons shows its ordinary first visit before and after.

The published artifact was also opened on all 46 routes using Playwright WebKit's iPhone 13 profile. The mobile check covered horizontal overflow, decoding visible images, script errors and the link back to the correct primary reference. Separate Chrome tests exercised the page-specific actions, install identities and offline reloads. The ordinary demos reopen from their own service workers; the mall serves its dedicated reconnect screen offline. Device installation and physical-phone input were outside this review.

## Recreate the comparison sheets

With Pillow installed, run `python scripts/render_anchor_audit.py <captures-directory>`. Supply the original browser PNGs as `<company>/<before|after>/<version>-<width>.png` for both viewport sizes. Browser screenshots and served HTML are independent evidence; the tool only arranges the images.
