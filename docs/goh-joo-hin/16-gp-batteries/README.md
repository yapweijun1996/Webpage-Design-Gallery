## Interior design

Make the eyelet the architectural cue and the paper-pack shelf the actual merchandise focus. Use restrained lime, warm white and cool steel in short blocks.

| Element | Placement and interaction |
| --- | --- |
| Main display | Perforated eyelet demonstration rail, local XYZ (-1.56, 0.081, -1.28), yaw 5°. Retain the original eyelet fixture with the loop composition visible from the main aisle. |
| Visitor route | Threshold local XZ (0, 5). Keep the tested centre passage between the display elements. |
| Fixtures and use points | Keep cell shapes on the back shelving and show the eTag shape separately near the loop. |
