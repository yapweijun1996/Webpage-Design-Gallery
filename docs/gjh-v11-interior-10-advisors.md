# GJH V11 interior and HUD: ten-advisor review

Date: 15 November 2026 (Asia/Singapore).

## Scope and evidence

Ten independent agent advisors reviewed spatial planning, art direction, modeling, lighting/materials, wayfinding, camera composition, merchandising, HUD, accessibility and performance. These are agent reviews, not interviews with ten human professionals. The task is advisory; no application code, model, collision or release changes were made.

The target is the current uncommitted local V11 at `http://127.0.0.1:23149/demos/corporate/gjh/v11/index.html`, not the separately published Gallery collection. The owner supplied a 639x826 view. Additional captures use headless Chrome/ANGLE Metal at 639x826 and 1440x1000, with the welcome dialog and tutorial dismissed. Three storefront views were captured after using the existing scene test interface to approach them. Some early advisor observations used tutorial-obscured or historical captures; final visual synthesis uses the unobstructed views.

Evidence: [capture state and source hashes](evidence/gjh-interior-advisors.json), [639px atrium](screenshots/gjh-interior-advisors/atrium-639.png), [1440px atrium](screenshots/gjh-interior-advisors/atrium-1440.png), and the New Moon/MILI/GOGO captures in the same folder. Atrium snapshots reported 137 and 152 draw calls respectively, with no captured JavaScript `pageerror` events. These snapshots do not establish a performance budget, sustained frame rate, clean network/console, collision acceptance or full E2E pass.

## Combined direction

Retain the green, warm wood and brass identity. Make this a legible food-and-lifestyle destination with one central landmark, recognizable store entrances and a calm HUD. Prioritize circulation and view composition before investing in detailed replacement models. Visual taste recommendations below are proposals; inferred geometry risks require browser reproduction.

The subsequently supplied 200-asset backlog is preserved as an [unchanged source reference](references/gjh-interior-200-assets-v1.md). The [interior asset plan](gjh-v11-interior-asset-plan.md) reconciles its counts, proposed dimensions, interaction tags, loader/LOD constraints and phased pilot with this review. The 200 candidates are a planning inventory; they do not supersede the circulation-first recommendation or certify existing models against the new gates.

## Recommended order and trade-offs

1. **P1: navigation and composition.** Validate kiosk/cart clearance, sculpture placement, store sightlines and camera framing. Unify help/map/prompt ownership. This has priority over adding visual detail.
2. **P2: a small original model kit.** Build the accepted central feature, table/counter variants and correct furniture proportion/grounding. Keep editable sources and reusable instances; do not replace all architecture with unique meshes.
3. **P2: lighting and store differentiation.** Tune existing lighting/materials, then stage each store around its supported content. Branded product additions require separate source evidence.
4. **Acceptance before release.** Reproduce suspected collision issues, inspect portrait/desktop and all action/overlay states, then run relevant movement/cart/seat/map/product/fallback and payload regressions. The ten advisory reviews are not substitutes for these checks.

Resolve competing suggestions in this order: settle circulation before the centerpiece's final mesh; establish lighting/material hierarchy before adding reflection assets; verify loader contracts before authoring textured furniture; preserve functional fallback/list access while reducing HUD clutter. The recommendation to simplify the sculpture and the recommendation to model it more carefully can coexist as one simpler, better-authored landmark.

## Coverage limits

This review captured two atrium widths and three store approaches and inspected current source. It did not run full E2E, physical-device or screen-reader testing, measured collision journeys, contrast/axe scans, complete performance profiling, or packaging/brand-rights certification. Current local visitor/onboarding/elevator work remains outside this advisory implementation scope. No commit or push is included.
