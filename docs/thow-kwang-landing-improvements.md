# Thow Kwang Pottery Jungle landing designs

A visitor can start by reading a kiln drawing, planning a group visit or studying a particular object. Each of these fifteen entrances now puts a different action beside the evidence a visitor needs for it. Shared local type, photographs and diagrams connect the collection. The images are illustrative studies. The operator owns tour arrangements, directions and workshop bookings. [Company research and source notes](../demos/heritage/thow-kwang/README.md)

## Evidence and maintenance

The company browser check opens each edition at 320, 390, 768 and 1440 CSS pixels. It runs the route-specific keyboard journey at 390 pixels and also opens every page with JavaScript disabled. The capture option writes real 390-, 768- and 1440-pixel screenshots and a 720-pixel desktop thumbnail. It navigates at the capture width before checking the initial paint, which avoids stale sticky-header tiles after a live breakpoint change. [Reproducible browser checks](../demos/heritage/thow-kwang/browser_checks.py)

The tour and workshop decisions use the operator’s published conditions. The classroom question, contour overlays, material studies and walking prompts are independent educational content.
