# GJH V11 stage 0: follow-up fixes and verification

Date: 15 November 2026 (Asia/Singapore)  
Scope: fix the three functional and test findings from the [stage 0 baseline](gjh-v11-stage0-baseline.md). The 17-store expansion and the baseline's visual finding F3 remain in later redesign stages.

## Results

1. **F1 — narrow header:** At 320×568, the directory button previously extended to x=341.86 outside a 320px viewport. At widths up to 360px its complete label now wraps inside an 80×44px button. Its visible focus indicator has a shorter offset so it fits between the bag and viewport edge. The final 320px result is x=229.94–309.94, with a 5px focus-ring extent and the bag ending at x=224.94. [Bounds for five viewports](evidence/gjh-stage0-fixes-20261115/header-bounds.json), [320px keyboard focus](evidence/gjh-stage0-fixes-20261115/screens/header-focus-320.png), [390px](evidence/gjh-stage0-fixes-20261115/screens/header-focus-390.png), [desktop](evidence/gjh-stage0-fixes-20261115/screens/header-focus-1440.png).
2. **F2 — seat test path:** The unmodified V2 lifecycle test reproduced the kiosk collision from the baseline. Both seat suites now share one path helper which walks around the kiosk and plinth to each seat's existing interaction point; collision detection and the original mode/seat assertions remain enabled. The complete V2 mode lifecycle passed at 390, 768 and 1440px; the 390px run included all eight seats. The separate eight-seat animation and interruption suite also passed on the preceding isolated snapshot. [Mode results](evidence/gjh-stage0-fixes-20261115/modes-results.json), [seat results](evidence/gjh-stage0-fixes-20261115/all-seats-results.json).
3. **F4 — gamepad test fixture:** The real frame loop can still hold the last sampled gamepad look value when the test neutralizes the synthetic stick and immediately calls the manual stepping hook. A controlled diagnostic reproduced a yaw of −7.35 radians and missed MILI without a host frame; after two host frames consumed the neutral input, yaw remained zero and the original path reached MILI. This confirms a timing mechanism capable of producing the observed timeout, though it does not independently prove every historic failure had that cause. The fixture now yields to two host frames, walks around the table using its live collider, then returns control to the real frame loop for the synthetic gamepad button press. Movement, camera, inspect, tutorial and modal assertions were retained. Three consecutive runs passed on the current-source snapshot. [Diagnostic trace](evidence/gjh-stage0-fixes-20261115/gamepad-probe.jsonl), [diagnostic script as run](evidence/gjh-stage0-fixes-20261115/gamepad-probe-used.py), [runs 1](evidence/gjh-stage0-fixes-20261115/current-onboarding-1.log), [2](evidence/gjh-stage0-fixes-20261115/current-onboarding-2.log), [3](evidence/gjh-stage0-fixes-20261115/current-onboarding-3.log).

The timing repair is in the **test fixture**; it is not a claim that a physical gamepad or real user navigation was repaired or verified. The seat fix similarly changes the scripted route, not the kiosk or seat colliders.

## Verification and provenance

Tests used real headless Chrome with requested ANGLE Metal on the local Apple M4, with Playwright and an isolated source copy. The direct header test used DPR 2, touch emulation below 1000 CSS px, and blocked service workers. It checked the actual button, text, five hit points, keyboard focus ring and directory/3D round trip at 320×568, 390×844, 639×826, 768×1024 and 1440×900. The mode lifecycle and onboarding tests used their own existing context settings; they do not all use DPR 2.

- `tests/browser_gjh_header_bounds.py`: passed at all five viewports, including the final focus-offset adjustment.
- `tests/browser_gjh_modes.py`: passed on the later snapshot at 390×844 (81 snapshots), 768×1024 and 1440×900 (42 each), including all eight seat modes at 390px. [Log](evidence/gjh-stage0-fixes-20261115/modes-log.txt).
- `tests/browser_gjh_onboarding.py`: passed three consecutive times on that later snapshot, including the synthetic standard-gamepad press through the actual application frame loop.
- `tests/browser_gjh_all_seats.py`: all eight transitions, stand, modal pause, interruption and reset checks passed on the preceding snapshot, using `GALLERY_WEBGL_BACKEND=metal`.
- `scripts/build_gallery.py --check` and 11 `test_gallery.py` unit tests passed; the generator was also run in the working tree and its check passed after the final CSS change.
- `browser_gallery.py`, `browser_gjh_demos.py`, and `browser_pwa.py` passed in the preceding isolated snapshot. The legacy demo runner was not supplied an axe bundle, so its printed zero axe violations are not an automated axe audit. [Gallery](evidence/gjh-stage0-fixes-20261115/browser_gallery.log), [demos](evidence/gjh-stage0-fixes-20261115/browser_gjh_demos.log), [PWA](evidence/gjh-stage0-fixes-20261115/browser_pwa.log).

The worktree contained unrelated concurrent changes, so screenshot-writing tests ran in isolated copies. On the later snapshot, the mode and onboarding runs preceded the addition of the **320px-only focus-offset rule**; that final rule was subsequently verified with the header suite. At the first comparison, the V11 tree, shared onboarding files and the four directly modified test files matched the later isolated snapshot. A subsequent concurrent change to `assets/newmoon-detail-preview.js` released captured pointers on page visibility change; it was not included in these browser runs. The [source manifest](evidence/gjh-stage0-fixes-20261115/source-manifest.json) records the final header-test source and the earlier CSS hash for the mode and onboarding runs. The standalone seat and gallery suites used an earlier snapshot, so their pass is not a claim they were rerun against every subsequent unrelated page edit. The diagnostic script contains the original temporary path; adapt it before reuse.

## Remaining limits

No physical phone, tablet, controller, Safari, screen reader or field-performance test was performed. The baseline's material, elevator, ring, storefront and furniture design observations remain open in the phased redesign. These fixes do not implement the expanded mall or seasonal themes.
