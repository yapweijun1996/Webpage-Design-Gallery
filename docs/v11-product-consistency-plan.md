# Existing-source product consistency acceptance

Task: match each deployed model, label, name and record against the existing
verified source data. The Phase 2 contract explicitly allows estimated panel
order/spacing and the disclosed Mexico 121-degree blank sector. It does not require
print masters or measured physical-can certification. Earlier audit notes applied
that stronger condition; this acceptance corrects that interpretation without
changing the task's source-consistency requirement or the physical-device gate.

Required proof before marking this task complete:

1. Refresh all four official product pages and eleven original packshots; verify
   current title/record mapping, page references and exact original image hashes.
2. Match each actual deployed GLB and embedded label image to its pinned model,
   photo-derived texture and per-SKU source image manifest. AI comparison variants
   must not replace the primary photo-derived texture.
3. Render the exact GLB front/back/NIP panels and compare their legible origin,
   weight, South Africa 4-5pcs and other visible factual content with the authentic
   source. No cross-SKU or invented facts; record soft/unreadable microtext as
   unverified. Estimated placement is not permission for wrong content.
4. Verify live interaction/preview opens the right record/name/packshot and preserves
   conceptual/estimated packaging and Mexico blank-sector disclosures.
5. Record catalogue 7.5 × 7.5 × 12cm separately from nominal GLB bounds and avoid
   equating either with a measured manufacturing specification. Preserve existing
   geometry, assets, source originals and estimated-scale disclosure.

This is one task with a source audit, independent visual/content review and a
focused documentation release. No runtime change is anticipated; a confirmed
mismatch would require its own targeted fix and affected regression checks.
Physical iPhone/Android, actual insets and screen readers remain separately open.
