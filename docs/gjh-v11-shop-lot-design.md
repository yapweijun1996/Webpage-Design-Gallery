# GJH V11 shop-lot design

Independent virtual-mall concept. Slot allocation and brand-kit/product evidence are supplied design inputs, not proof of current tenancy, distribution, authorization, stock, or real premises. Storefront signs use the supplied logo assets and brand names as requested; product displays stay within each row's evidence level. Do not add real prices or medical claims. Hero products use their listed physical package/equipment dimensions when verified; otherwise use a clearly generic category-scale stand-in, never a false branded replica. Each storefront is glazed, with a visible display but no walkable interior.

Expanded layout is default. North storefronts S01–S05 face south; west S06–S11 face east; east S12–S17 face west. Existing runtime geometry, scale and stable IDs stay unchanged. Interior LOD is omitted for distant lots (facade + sign); nearby lots show a single compact display group. Keep the New Moon red flagship accent alongside the shared forest-green, ivory, champagne-gold, warm-wood and light-stone palette. Target <=200 draw calls at the default view; trim distant interiors first if the measured budget requires it.

## Source and model boundary

Hero names and evidence levels are from `~/omp-tasks/brand-products.tsv`; category, themes and source links are in `demos/corporate/gjh/v11/assets/brand-kit/brand-kit.json`. Slot geometry comes from `demos/corporate/gjh/v11/assets/expanded-layout.js`, translated from the stage-1 spatial plan while preserving current shop placement. All 17 logo files are present under `demos/corporate/gjh/v11/assets/brands/` and mapped in `logo-sources.json`.

The upstream Blender checkout contains a validated `gjh-m056-premium-wall-shelf-straight` export and existing `mall-glass-showcase` export. The v11 checkout already vendors `mall-display-shelf.glb`, `mall-glass-showcase.glb`, `gjh-m056-shelf-lod1.glb`, and four New Moon can models. Reuse is limited to local assets with their source/validation receipts checked during implementation; no new Blender models are to be made. No matching verified branded hero model is assumed for S02–S17. Product-specific model gaps and any rejected/unavailable candidate assets must be recorded here during stages 3–4.
