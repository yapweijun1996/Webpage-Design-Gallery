# The Drinks Index

An independent Singapore drinks guide for Yeo Hiap Seng Limited. The six entries, descriptions and pack formats in the HTML are based on the individual Yeo’s Singapore product pages linked from the cards, reviewed on 17 November 2026. The three drink families are editorial groupings. The [company history](https://yeos.com.sg/about-us/history-heritage/) supplies the historical dates.

Each product remains readable with JavaScript disabled. JavaScript adds family filters and controls for the featured drinks. Product and history links lead to the official site. The hero and six ingredient still lifes are original AI-generated illustrations of serving ideas. They do not depict official packs.

Manrope and Instrument Serif are self-hosted under the SIL Open Font License. The font licences accompany the assets. The Instrument Serif files came from Google Fonts, and the Manrope Latin file uses the gallery’s existing licensed copy. [Instrument Serif source](https://github.com/google/fonts/tree/main/ofl/instrumentserif) · [Manrope source](https://github.com/google/fonts/tree/main/ofl/manrope)

From the repository root, run `python tests/browser_yeos_drinks.py` for the responsive, keyboard, filtering and no-JavaScript checks. Add `--capture` to refresh the three catalogue screenshots and thumbnail, then run `python scripts/build_gallery.py` to update the gallery.
