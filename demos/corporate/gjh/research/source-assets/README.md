# GJH Website Reference Assets

This folder contains third-party media downloaded for research and design reference. `manifest.json` records source URLs, referring pages, status, file size and SHA-256. File names include a content-hash prefix. Downloaded media is ignored by Git and is not included in the Pages artifact. Confirm permission with the rights holder before reuse, redistribution, or publication.

The inventory covered the public page sitemap and the requested homepage. It examines media URLs directly present in page HTML; it does not crawl linked CSS, dynamically loaded content, third-party hosts, or the complete website infrastructure. A failed page and excluded external-host URLs are recorded in the manifest. This is not a complete website archive.
