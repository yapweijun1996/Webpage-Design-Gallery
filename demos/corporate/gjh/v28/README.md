# Goh Joo Hin v28 — The Distribution Desk

Independent concept, not affiliated with or endorsed by Goh Joo Hin Pte Ltd.

Run `python3 -m http.server 8000` from the repository root and open [the demo](http://localhost:8000/demos/corporate/gjh/v28/). The page uses local assets and plain HTML, CSS and JavaScript.

- Choose a division to jump to the filtered brand shelf. Use the shelf chips to change or clear the filter.
- Enter a company, market and category to prepare a short English enquiry in the browser. Copy the draft and use the contact link to open GJH’s official site.
- English is in the HTML. The language switcher remembers the selected language when browser storage is available. Simplified Chinese and Malay are drafts awaiting fluent review.
- [Asset provenance](assets/sources.json) records repository-relative sources, SHA-256 hashes and file sizes. [Design notes](../../../../docs/gjh-v28/design-notes.md) describe section intent and factual boundaries.
